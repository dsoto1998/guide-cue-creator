# Guide Cue Creator

Ableton Live 세션(`.als`)을 읽어 로케이터를 오디오 큐 파일과 매칭하고, 비트 0에서 전용 가이드 큐 트랙에 바로 사용할 수 있는 단일 스테레오 WAV(`guide_cues.wav`)를 렌더링합니다.

---

## 포함된 항목

```
cue_creator.html    ← 앱 파일 (이 파일을 열어주세요)
GUIDE CUES/         ← 섹션 큐 오디오 라이브러리 (내장)
```

---

## 시스템 요구사항

- **Chrome 또는 Edge** (권장) — 최초 실행 후 클릭 없이 폴더 접근
- **Firefox** — 사용 가능, 브라우저 세션마다 폴더를 다시 선택해야 할 수 있음
- 인터넷 연결 필요 (CDN에서 pako, Fuse.js, Dexie 로드)

---

## 빠른 시작

1. `cue_creator.html`을 더블클릭 — 기본 브라우저에서 열림
2. **폴더 선택**을 클릭하고 `GUIDE CUES/`가 있는 폴더를 선택
3. 드롭다운에서 **언어** 선택
4. `.als` 파일을 업로드 영역으로 드래그 (또는 클릭하여 탐색)
5. 큐 테이블 확인 — 초록색 = 좋은 매칭, 노란색 = 낮은 신뢰도, 빨간색 = 매칭 없음
6. **미리듣기** 클릭 (또는 **스페이스바** 누르기)로 미리 청취
7. **WAV 렌더링** 클릭 — `guide_cues.wav` 다운로드
8. `guide_cues.wav`를 Ableton 세션의 비트 0에 전용 트랙으로 드래그

Chrome/Edge에서는 폴더 선택이 기억됩니다. 2단계는 최초 1회만 설정하면 됩니다.

---

## 앱 기능

- 각 섹션 큐를 로케이터 **1마디 전**에 배치
- 처음 2마디에 **카운트오프** 생성 (4/4박자 기준 비트 0–7)
- 카운트오프 영역 내의 섹션 큐 억제
- `count off` 또는 `next song`으로 명명된 로케이터 건너뜀
- 템포 자동화 지원 (가변 BPM 세션)

---

## 큐 테이블 컨트롤

| 열 | 설명 |
|----|------|
| 로케이터 | 읽기 전용 — .als 파일에서 가져옴 |
| 매칭된 큐 | 자동 매칭을 재정의하려면 편집 |
| 신뢰도 | 초록 ≥ 80% · 노랑 ≥ 50% · 빨강 < 50% |

---

## 타임라인 컨트롤

| 동작 | 결과 |
|------|------|
| 클릭 | 위치로 이동 |
| 스페이스바 | 재생 / 일시정지 |
| Ctrl+스크롤 또는 핀치 | 커서 방향으로 확대/축소 |
| +/− 버튼 | 확대/축소 |
| 초기화 | 전체 세션을 너비에 맞춤 |
| 재생 위치 따라가기 | 자동 스크롤 토글 |

---

## 출력 사양

| 설정 | 값 |
|------|---|
| 샘플 레이트 | 48,000 Hz |
| 채널 | 스테레오 |
| 비트 심도 | 16비트 PCM |
| 파일 | `guide_cues.wav` |
